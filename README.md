# Actuarial Concepts Covered

## Loss Ratio

Measures the proportion of premium consumed by claims.

Loss Ratio = Claims Incurred / Premium Earned

---

## Combined Ratio

Measures overall underwriting profitability.

Combined Ratio = Loss Ratio + Expense Ratio

Interpretation:
- Combined Ratio < 100% → Profitable underwriting
- Combined Ratio > 100% → Underwriting loss
